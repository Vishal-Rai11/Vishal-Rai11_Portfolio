## Upload in 5 separate commits
GitHub's website rejects large uploads made together, so upload one file per commit:
1. `index.html` + `README.md` → Commit
2. `Yipee-Ad.mp4` → Commit
3. `R1_final.mp4` → Commit
4. `R2_final.mp4` → Commit
5. `R3_final.mp4` → Commit

Use **Add file → Upload files** for each. Then **Settings → Pages → Deploy from a branch → main / (root) → Save**.
